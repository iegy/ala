# آلة كاتبة

موقع تطبيق **آلة كاتبة** وصفحة **الجواب الحي**، وكمان مكان نزول الإصدارات.

- الموقع: https://iegy.net/ala/
- الجواب الحي: `https://iegy.net/ala/letter/#p.…` — الجواب كله جوه اللينك (مضغوط، ولو بكلمة سر بيبقى متشفّر AES-GCM)، ومفيش أي حاجة بتتخزن على سيرفر.
- التحميل: [آخر إصدار](https://github.com/iegy/ala/releases/latest)
